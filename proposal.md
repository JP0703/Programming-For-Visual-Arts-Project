# The Pits of Trial

## Repository
https://github.com/JP0703/Programming-For-Visual-Arts-Project

## Description
A game where the goal is to survive as long as possible as more obstacles spawn.

## Features
- Difficulty Progression
	- The game gets harder and harder till until a certain point where the difficulty maxes out. More obstacles and faster speeds.
- Dash
	- Pressing a button will allow the player to dash, having i-frames while doing so
- Pause feature
	- Pressing a button will pause the game
- Restart
  - Pressing a button will restart the game back to the beginning during pause
- Difficulty Selection
  - When the game starts, the player will have an option to choose a difficulty, which starts at a different time of the difficulty and even caps for lower difficulties.

## Challenges
- How to implement a pause screen and a functional restart button
- How to randomly spawn obstacles that goes more often
- How to make a invisible hitbox of the player
- How to make a dash that removes the hitbox of the player until it ends
- How to create a difficulty selection work
- How to make projectile speeds faster

## Outcomes
Ideal Outcome:
- Create a survival game that gets difficult over time with obstacles spawning more and moving faster. It has a movement option of dashing to get a bit of i-frames to dodge trick situations. It can pause and restart the game. You can choose the difficulty when the game starts up.

Minimal Viable Outcome:
- Make a game that gets difficult overtime with more obstacles as time goes on by spawning more often and moving faster. The game is able to pause everything and unpause.
